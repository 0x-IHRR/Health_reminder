[h1] HealthReminder
[p] 一个极简健康提醒应用：按正在操作电脑的累计时间，轻量提醒护眼活动、喝水和坐姿肩颈放松。提醒发出后会自动进入下一轮计时。
[p] 目前支持：
[li] macOS 菜单栏版本
[li] Windows 系统托盘版本
[h3] macOS
[p] 下载 GitHub Releases 中的最新 DMG，打开后把
[code] HealthReminder.app
[code] /Applications
[p] ，再启动应用。
[p] 如果是从源码本地打包：
[pre] bash Scripts/package_app.sh
open build/HealthReminder.app
[p] 第一次运行时，macOS 会请求通知权限。允许后，提醒会以系统通知形式出现。
[h3] Windows
[p] 下载 GitHub Releases 中的
[code] HealthReminder-<version>-win-x64.zip
[p] ，解压后运行
[code] HealthReminder.exe
[p] Windows 版是自包含包，不需要额外安装 .NET。第一次运行后会默认开启当前用户的开机自启，可在托盘菜单里关闭。
[li] macOS 版常驻菜单栏，Windows 版常驻系统托盘，不显示主窗口。
[li] 所有提醒都按键盘或鼠标活跃使用时间累计。
[li] 离开电脑超过 60 秒时暂停累计。
[li] 内置提醒：
[li] 放松眼睛 / 起身活动：30 分钟
[li] 喝水：60 分钟
[li] 调整坐姿 / 放松肩颈：90 分钟
[li] 提醒发出后自动进入下一轮，不需要手动确认。
[li] 多个提醒独立计时，其中一个提醒触发不会重置其他提醒。
[code] .app
[li] 启动时，会写入用户的
[code] LaunchAgents
[li] ，下次登录后自动启动。
[li] Windows 版会写入当前用户的
[code] Run
[li] 启动项，下次登录后自动启动。
